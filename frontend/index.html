Why patient / exam columns?

The server picks the row where patient_id and exam_id match this job (auto-generated or from Advanced). Multi-row batch CSVs need those keys.

GPU Stage 1 by default (8‑bit LLM when enabled — fastest on typical SCC GPUs).

More about Stage 1 on GPU

Wording can differ slightly vs full fp16; 8‑bit saves VRAM on shared nodes. See repo README.md for rationale.

Stage 1 on CPU uses full fp16 (slow); Mammo‑CLIP and Stage 2 still use GPU when available.

Stage 1 runs unquantized fp16 on the GPU. Best fidelity; needs an A100-class GPU.
